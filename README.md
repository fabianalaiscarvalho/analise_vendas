# Análise de Vendas com R
## Sobre o projeto
Projeto de análise de dados desenvolvido em R para avaliar o faturamento de uma empresa por loja e produto.

A análise utiliza dados de uma planilha Excel e aplica técnicas de exploração, manipulação e visualização de dados para comparar o desempenho comercial das lojas e dos produtos.

## Análises realizadas
- Cálculo do faturamento total.
- Comparação do faturamento por loja.
- Análise do faturamento por produto em cada loja.
- Criação de gráficos para visualização dos resultados.

## Bibliotecas utilizadas

- readxl: importação de dados do Excel.
- dplyr: manipulação e sumarização dos dados.
- ggplot2: visualização dos resultados.
- utf8: suporte a operações relacionadas à codificação de caracteres.

## Objetivo
Praticar técnicas de análise de dados com R, transformando dados de vendas em informações que facilitam a comparação do desempenho comercial
